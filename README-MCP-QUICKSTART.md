# MCP quickstart

The quickstart now lives in [Use MCP](docs/use/mcp.md), with native and Docker
setup, client configuration, and a first-query workflow.

For shared Azure state, see [Authentication](docs/use/authentication.md). For
local builds versus an explicit image, see [Container images](docs/containers/use-image.md).

The existing `docker-mcp.sh` and `docker-mcp.bat` launcher paths remain supported.
